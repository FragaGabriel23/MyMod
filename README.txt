# My Mods

This mod adds custom recipes to Minecraft through mod integrations.

## Features

- **IC2 Integration**: Adds recipes for IC2 machines (like the Macerator).
- **AE2 Integration**: Allows converting Minecraft Quartz into Nether Quartz Dust (AE2).

## Recipes

- **Macerator Recipe**: Converts Minecraft Quartz (`minecraft:quartz`) into Nether Quartz Dust (`appliedenergistics2:material` with meta 3).

## Installation

1. Build the mod `.jar` file.
2. Place it in the `mods` folder of your Minecraft directory.
3. Launch Minecraft with Forge 1.12.
